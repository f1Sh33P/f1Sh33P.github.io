代码规范

单行代码最多包含一个块级元素， 空行使用 <p><br></p> 表示。 缩进 使用 2 个空格。 空白字符 删除 trailing whitespace，保留 final new line。 注释 注释放在对应代码的上方或右方。 标签 html 标签写成 <img>，而非 <img /> css 用单引号，html 用双引号 文件路径 外部链接使用绝对路径，内部链接使用根目录的相对路径。 命名 文件名：使用小写字母，用 hyphen 进行连接（kebab case）。使用缩写，如 specification 缩写为 spec，architecture 缩写为 arch。 HTML 和 CSS：标签和选择器均使用小写字母，配合 kebab case。 JavaScript：变量名使用 lower camel case。

文档语言设置为 zh-CN。

格式化

HTML 使用 VS Code 的默认 formatter，取消每行字数限制。CSS 不使用 formatter。
