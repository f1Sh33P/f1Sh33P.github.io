布局

清除默认边距，使用 border-box 进行布局。

  • max-width：设置为 740px。

  • margin：设置为 0 auto。

  • padding：设置为 0 20px 32vh。

颜色

采用深色主题。

  • 背景：#3c3c3c
  • 文字：#e3e3e3
  • 高亮：#ffffff22
  • 黑色：#202020
  • 灰色：#757575
  • 黄色：#e8c37d
  • 蓝色：#70dae6
  • 紫色：#dc91f2

一般情况下，选中文本背景使用高亮，代码块背景使用黑色，边框使用灰色，代码使用黄色，链接使用蓝色，访问过的链接使用紫色。

字体

  • font-family：正文使用 Inter 和 Noto Sans SC，调整小写 l、省略号及间隔号的样式；代码使用 Noto Sans Mono。均为可变字体。

  • font-weight：常规文本设置为 350，粗体设置为 650。

  • font-size：以 16px 为基准，代码和表格设置为 15px，二级标题 1.6em，三级标题 1.2em，四级标题 1em。电脑端，以 18px 为基准，代码和表格设置为 16px。

  • line-height：以 26px 为基准，二级标题 1.3，三级标题 1.4。电脑端，以 28px 为基准。

边距

  • margin：以 6px 0 为基准，二级标题 2.2em 0，三级标题 36px 0 8px，四级标题、列表、代码块和表格与正文相同。电脑端，以 8px 0 为基准，三级标题设置为 38px 0 10px。

  • padding：页面设置为 0 20px 32vh，列表 0 0 0 20px，代码块 16px 20px，引用块 0 0 0 16px，表格数据 2.5px 8px。

边框

border-radius：代码块设置为 8px。

border-left：设置为 4px 灰色实线。

溢出

overflow-x：代码块设置为 auto。
