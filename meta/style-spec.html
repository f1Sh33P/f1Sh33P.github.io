样式规范

颜色

采用深色主题。 背景：#3c3c3c 文字：#e3e3e3 选中文本背景：#ffffff22 代码块背景：#202020 代码：#e8c37d 链接：#70dae6 访问过的链接：#dc91f2 边框：#757575

文本

文档语言设置为 zh-CN。 font-family：西文使用 Inter 可变字体，来自 Rasmus Andersson。中文使用 Noto Sans SC 可变字体，来自 Google Fonts。调整小写 l、省略号及间隔号的样式。 font-weight：普通文本设置为 350，粗体文本设置为 650。 font-size 和 line-height：以 18px / 28px 为基准。h2 设置为 1.6em / 1.3，h3 设置为 1.17em / 1.4。 margin：以 8px 0 为基准。h2 设置为 2em 0，h3 设置为 38px 0 10px。

列表

padding-left：设置为 20px。

代码

font-family：使用 Noto Sans Mono 可变字体，来自 Google Fonts。 font-size：设置为 16px。 padding：代码块设置为 16px 20px。 border-radius：代码块设置为 8px。 overflow-x：代码块设置为 auto。

表格

布局

使用 border-box 进行布局。 max-width：设置为 740px。 margin: 设置为 0 auto。 padding：设置为 0 20px 10vh。
